This page is open as a file — the handoff cannot work

Its origin is "null". Scribe can receive messages from it, but postMessage has no way to send anything back to a null origin, so Scribe stays silent and the popup sits on “Starting your session…” forever.

Serve it over http instead:
cd ~/Desktop && python3 -m http.server 8080
then open http://localhost:8080/emr-demo.html
